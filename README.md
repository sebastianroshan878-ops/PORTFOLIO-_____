## 💻 Local Development Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/sebastianroshan878-ops/PORTFOLIO-_____.git
cd PORTFOLIO-_____
npm install
npm run dev
```

The application will start at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
